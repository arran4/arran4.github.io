arran4.github.io brings several kinds of public work together: versioned software releases, technical writing, curated resources and a directory of published project pages.

## Find a recent release

The homepage presents dated release tags from a deliberately selected set of public GitHub repositories. Each entry links to the technical release record, rather than treating a version number as a separate announcement.

## Read about the work

Articles are a different kind of material from release records. An introduction explains a project, a getting-started guide helps a reader use it, and a what's-new article explains a meaningful change with evidence. Technical blog posts remain available through the [separate blog](https://arran4.github.io/blog/).

## Browse projects and resources

The directory is searchable and grouped by purpose. It links to public project sites and application landing pages; a repository being listed does not mean that it has been individually endorsed or recently released. Curated references have their own section.

## How the website is put together

The homepage uses Hugo with project-owned HTML templates, styles and small amounts of plain JavaScript. Existing legacy subpages still use the previous theme until a separate migration preserves their behaviour.
